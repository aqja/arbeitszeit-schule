Entwickele daraus einen optionalen Arbeitszeitplaner, mit dem konkrete Arbeitszeiten für eine normale Woche definiert werden können. 
- Input notwendig: Start- und Endzeit und Dauer der Pause für jeden Werktag (Mo-Fr)
- daraus Berechnung der wöchentlichen Arbeitszeit und Teilzeitmodell (Prozent, 39h=100%)
-> splitte Ergebnisse: Tagesverteilung und Jahresarbeitsstunden/Wochenarbeitszeit bei 100% soll Ergebnis von Input Schuljahr und flexibler Ferientage sein; Input Arbeitszeitplaner bestimmt Anteil für Arbeitszeitmodell auf Basis der Wochenarbeitszeit
